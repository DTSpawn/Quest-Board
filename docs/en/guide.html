User Guide

Step-by-step instructions for GMs: create boards, publish notices, manage templates and archive entries, and customize the appearance.

1. Creating a Board

  1. Open the Quest Board manager.
  2. Create a new board and give it a name.
  3. Choose whether it should appear in the players’ board manager.
  4. Save the board. New boards are hidden from players by default.

Board visibility does not override Foundry permissions for the scene or its tile.

2. Placing a Board on a Scene

  1. Open the desired scene.
  2. In the manager, use the action to place the board icon on the scene.
  3. The icon is created as a Foundry tile. Move and resize it with the standard scene tools.
  4. Click the icon to open the corresponding board.

3. Creating a Notice

  1. Open a board and choose to create a notice.
  2. Enter a title, short description and main text.
  3. Optionally choose Main Story, Jobs, Wanted, Exploration or Other, or leave the category unset.
  4. Enter the author’s name; it appears at the bottom as a signature.
  5. Optionally add an external link or select a Foundry Journal entry or page.
  6. Save the notice. Players will not see it until it is published.

4. Publishing and Expiration

Enable publishing in the editor when the notice is ready. Unpublishing returns it to draft status; the GM sees an indicator for unpublished notices.

Set a duration in in-game days to limit availability. When it expires, the published notice is moved to the archive with the “Expired” status.

5. Generating a Random Notice

  1. Open the board where you want to add a flyer.
  2. Make sure the desired visual theme is selected.
  3. Click “Random Notice”.
  4. The module selects a notice from the library for the current theme and publishes it immediately.

No category selection or intermediate editor is required. The same notice may be selected more than once.

6. Personal “Saved Notices” List

  1. Find a notice on an available board.
  2. Click “Take Notice”.
  3. An independent copy is saved in your personal “Saved Notices” section.
  4. Open your personal list to revisit saved posts.
  5. Delete a saved copy when you no longer need it.

Deleting a saved copy only affects your personal list. The original notice remains unchanged.

7. Working with Templates

  1. Save a notice as a template in the editor and give it a name.
  2. Open the template manager to browse saved templates.
  3. Select a template to load it or create a new notice from it.
  4. The new notice opens as an unpublished draft. The original template remains unchanged.

8. Notice Archive

The archive contains Completed, Expired, Withdrawn and Failed notices. The GM can view, restore or permanently delete an entry.

A restored notice returns as a draft: publishing is disabled and its expiration is reset.

9. Customizing Appearance

  1. Open Quest Board appearance settings.
  2. Choose one of the 11 built-in themes.
  3. To use custom images, enable custom image mode and enter file paths for the board, paper, seal and scene icon.
  4. You can also hide fasteners and category icons.
  5. Save. Empty custom image fields use the selected theme’s default images.

The custom scene board icon is configured separately from the general custom images option.

Installation and Updates

  1. Download the ZIP from the Releases page.
  2. Extract the archive. It should contain a quest-board folder.
  3. Move it into Data/modules/. The module.json file must be directly inside Data/modules/quest-board/.
  4. Restart Foundry VTT and enable Quest Board in your world’s module settings.

Before updating, back up the module folder and replace it with the files from the new release.
