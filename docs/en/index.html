Notice boards for your game world

Quest Board lets GMs create independent boards, publish quests and generate random notices in the selected visual theme. Players can save posts to their personal “Saved Notices” list without changing the original notice.

Installation

  1. Download the ZIP from Releases.
  2. Extract the archive and locate the quest-board folder.
  3. Move it into Data/modules/ in your Foundry VTT installation.
  4. Restart Foundry VTT and enable Quest Board in your world’s module settings.

The module.json file must be directly inside Data/modules/quest-board/.
