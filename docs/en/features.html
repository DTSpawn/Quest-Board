Module Features

An overview of independent boards, notices, categories, templates, archive management and visual customization.

Notice Boards

Independent Boards

Create multiple boards with their own names and notices. Each board is managed separately.

Player Access

Control whether each board appears in the players’ manager. Boards can also be opened through a tile placed on a scene.

Scene Access

Place an interactive board icon on a scene so players can open it directly from the game world.

Notices and Categories

Drafts and Publishing

Create notices as drafts, edit them and publish them when ready. Players only see published notices.

Five Categories

Main Story, Jobs, Wanted, Exploration and Other. A notice can also have no category. Each category has its own icon.

Notice Content

Title, short description, full text and author signature, plus an external link or a Foundry Journal entry.

Saved Notices and Random Generator

Player Saved Notices

Players click “Take Notice” to save an independent copy in their personal “Saved Notices” section. Deleting the copy does not affect the original on the board.

Random Notice for GMs

GMs can instantly add a ready-made flyer. The generator uses the board’s current visual theme and publishes the selected notice immediately, without opening an editor.

Two Notice Libraries

The library follows Foundry’s interface language: 330 Russian notices and 220 original English notices, with 20 notices for each of the 11 themes.

Templates and Archive

Templates

Save notice drafts as templates and reuse them. Creating a notice from a template opens a new draft without modifying the template.

Archive

Completed, expired, withdrawn and failed notices are stored separately. Entries can be viewed, restored or permanently deleted.

Expiration

Set a duration in in-game days. When it expires, the notice is automatically moved to the archive.

Visual Customization

11 Built-in Themes

Medieval Fantasy, Dark Fantasy, High Fantasy, Sci-Fi, Cyberpunk, Solarpunk, Steampunk, Modern, Post-apocalyptic, Gothic Horror and Wild West.

Custom Images

Replace board, paper, seal, fastener and scene icon images using paths to your own files.

Display Options

Hide fasteners and category icons. The scene board icon has a separate image setting.

Quest Board supports Russian and English Foundry interfaces and is designed for Foundry Virtual Tabletop v14.
