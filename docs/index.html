Доски объявлений для вашего игрового мира

Quest Board позволяет ведущему создавать независимые доски, публиковать задания и управлять ими. Игроки видят доступные им доски и опубликованные объявления.

Установка

  1. Скачайте установочный ZIP из раздела Releases.
  2. Распакуйте архив и убедитесь, что внутри находится папка quest-board.
  3. Переместите её в Data/modules/ вашей установки Foundry VTT.
  4. Перезапустите Foundry VTT и включите Quest Board в настройках модулей мира.

Файл module.json должен находиться непосредственно в Data/modules/quest-board/, без дополнительной вложенной папки.
