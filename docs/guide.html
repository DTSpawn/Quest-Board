Руководство пользователя

Пошаговое руководство для ведущего: создание досок, публикация объявлений, управление шаблонами, архивом и внешним видом.

1. Создание доски

  1. Откройте менеджер Quest Board в интерфейсе модуля.
  2. Создайте новую доску и задайте ей название.
  3. В настройках доски укажите, должна ли она отображаться игрокам в менеджере.
  4. Сохраните доску. Новая доска по умолчанию скрыта от списка досок игроков.

Настройка видимости в менеджере не заменяет права доступа Foundry к самой сцене и размещённому на ней тайлу.

2. Размещение доски на сцене

  1. Откройте нужную сцену.
  2. В менеджере Quest Board используйте действие размещения значка доски на сцене.
  3. Значок создаётся как тайл Foundry. Переместите его и настройте размер стандартными инструментами сцены.
  4. При нажатии на значок открывается соответствующая доска.

3. Создание объявления

  1. Откройте нужную доску и выберите создание объявления.
  2. Заполните заголовок, краткое описание и основной текст задания.
  3. При необходимости выберите категорию: Основной сюжет, Заказы, Розыск, Исследование или Прочее. Можно не выбирать категорию.
  4. Укажите автора — он будет показан внизу объявления как подпись.
  5. При необходимости добавьте внешнюю ссылку или выберите запись/страницу Журнала Foundry.
  6. Сохраните объявление. Пока оно не опубликовано, игроки его не увидят.

4. Публикация и срок действия

В редакторе объявления включите публикацию, когда оно готово для игроков. Снятие публикации возвращает объявление в режим черновика; ведущий видит специальный индикатор неопубликованного объявления.

Если объявление должно действовать ограниченное время, задайте срок в игровых днях. Отсчёт использует игровое время Foundry. Когда срок истечёт, опубликованное объявление автоматически попадёт в архив со статусом «Просрочено».

5. Работа с шаблонами

  1. В редакторе объявления сохраните его как шаблон и задайте шаблону имя.
  2. Откройте менеджер шаблонов, чтобы просмотреть сохранённые заготовки.
  3. Выберите шаблон для загрузки в редактор или создайте на его основе новое объявление.
  4. Объявление, созданное из шаблона, открывается как новый неопубликованный черновик. Исходный шаблон остаётся без изменений.

6. Архив объявлений

В архив попадают объявления со статусами «Выполнено», «Просрочено», «Отозвано» и «Провалено». Ведущий может просмотреть запись, восстановить её или удалить окончательно.

Восстановленное объявление возвращается на доску как черновик: публикация выключена, а срок действия сброшен.

7. Настройка внешнего вида

  1. Откройте настройки оформления Quest Board.
  2. Выберите одну из 11 встроенных тем.
  3. Чтобы использовать собственные изображения, включите режим пользовательских изображений и укажите пути к файлам для доступных элементов: доски, бумаги, печати и значка сцены.
  4. Отдельно можно скрыть крепления и значки категорий.
  5. Сохраните настройки. Если поле пользовательского изображения пустое, используется изображение выбранной темы.

Пользовательский значок доски на сцене настраивается отдельно от общего переключателя пользовательских изображений.

Установка и обновление

  1. Скачайте установочный ZIP из раздела Releases.
  2. Распакуйте архив. Внутри должна быть папка quest-board.
  3. Поместите её в Data/modules/. Файл module.json должен находиться непосредственно в Data/modules/quest-board/.
  4. Перезапустите Foundry VTT и активируйте Quest Board в настройках модулей мира.

Перед обновлением рекомендуется сделать резервную копию папки модуля и заменить её содержимое файлами новой версии.
