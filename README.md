# Quest Board 1.3.6

**Quest Board** — модуль интерактивных досок объявлений для **Foundry Virtual Tabletop v14**. Позволяет ведущему создавать несколько независимых досок, размещать на них объявления и управлять тем, какие задания видят игроки.

## Возможности

### Доски и объявления
- Несколько независимых досок в одном игровом мире.
- Создание, редактирование и удаление досок и объявлений.
- Отдельная настройка доступности каждой доски для игроков.
- Публикация и снятие объявлений с публикации. Игроки видят только опубликованные объявления.
- Свободное размещение объявлений на доске с возможностью визуально организовать их расположение.
- Подпись автора, краткое описание и полный текст объявления.
- Необязательная сургучная печать.
- Внешняя ссылка и привязка к Journal Entry / странице журнала по UUID.
- Индикатор-глаз на неопубликованных объявлениях помогает ведущему отличать черновики от опубликованных заданий.

### Шаблоны
- Сохранение объявления в качестве шаблона.
- Просмотр шаблона.
- Создание нового объявления на основе шаблона.
- Удаление ненужных шаблонов.
- Создание из шаблона открывает обычный редактор объявления. Исходный шаблон не изменяется, а новое объявление создаётся неопубликованным.

### Архив
- Автоматическое перемещение объявлений в архив по истечении срока действия.
- Ручное архивирование через статусы **Выполнено**, **Провалено** и **Отозвано**.
- Просмотр архивных объявлений.
- Восстановление объявления на доску или окончательное удаление.
- Восстановленные объявления возвращаются неопубликованными; срок действия при восстановлении сбрасывается.

### Срок действия
Для опубликованного объявления можно задать срок действия в игровых днях. Расчёт выполняется через встроенный календарь Foundry VTT, поэтому учитывает календарную систему мира. По истечении срока объявление автоматически перемещается в архив.

## Категории заданий

| Категория | Назначение |
|---|---|
| **Основной сюжет** | Ключевые задания и сюжетные линии |
| **Заказы** | Работа, поручения и контракты |
| **Розыск** | Поиск и поимка целей, награды за них |
| **Исследование** | Разведка, открытия и изучение мест |
| **Прочее** | Задания, не подходящие под другие категории |
| **Без категории** | Объявления без выбранной категории |

У категорий есть собственные значки и цветовое оформление. Значки категорий можно отключить в настройках.

## Темы оформления

В модуле доступны 11 встроенных тем:

- Средневековое фэнтези
- Тёмное фэнтези
- Высокое фэнтези
- Научная фантастика
- Киберпанк
- Соларпанк
- Стимпанк
- Современность
- Постапокалипсис
- Готический хоррор
- Дикий Запад

Для тем предусмотрены соответствующие изображения досок, бумаги, печатей и значков размещения на сцене. Для неопубликованных объявлений используются тематические индикаторы.

### Пользовательские изображения

Ведущий может включить переопределение изображений и выбрать собственные файлы через файловый менеджер Foundry:

- значок доски на сцене;
- фон доски;
- фон объявления;
- изображение сургучной печати;
- изображение крепления (гвоздя, кнопки и т. п.).

Каждое поле необязательно: если путь не указан, используется ресурс выбранной темы. Модуль хранит пути к файлам, сами изображения остаются в хранилище Foundry. Пользовательские пути сохраняются при переключении темы. Для креплений и значков категорий предусмотрены отдельные переключатели отображения.

## Размещение и доступ

- Доску можно открыть из менеджера Quest Board.
- Ведущий может разместить на сцене специальный Tile, открывающий соответствующую доску.
- Менеджер доступен через инструменты сцены.
- Ведущий управляет досками, объявлениями, шаблонами, архивом и оформлением.
- Игрокам доступны только доски, разрешённые для просмотра, и только опубликованные объявления. Доску, скрытую из списка менеджера игроков, всё ещё можно открыть через размещённый на сцене Tile, если игрок имеет к нему доступ.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Поместите папку `quest-board` в `Data/modules/`. Если вы используете содержимое репозитория напрямую, убедитесь, что `module.json` находится в корне папки `quest-board`.
3. Перезапустите Foundry VTT.
4. Включите **Quest Board** в настройках модулей вашего мира.
5. Для настройки внешнего вида откройте **Настройки игры → Quest Board → Настройки оформления**. Настройки оформления доступны ведущему (GM).
