# Quest Board

**Quest Board** — интерактивные доски объявлений и заданий для **Foundry Virtual Tabletop v14**.

Создавайте независимые доски, публикуйте задания, используйте шаблоны и архив, выбирайте одну из 11 тем оформления или настраивайте собственные изображения.

## Загрузка и установка

**[Открыть страницу проекта: загрузка, установка и документация](https://dtspawn.github.io/Quest-Board/)**

На странице проекта собраны инструкции для пользователей, информация о версиях и ссылки на загрузку.

## Возможности

- Независимые доски объявлений и настройка доступа игроков.
- Публикация и снятие объявлений с публикации.
- Шаблоны объявлений.
- Архив заданий: выполненные, просроченные, отозванные и проваленные.
- Срок действия объявлений по игровому календарю Foundry.
- Пять категорий заданий и вариант без категории.
- 11 встроенных тем оформления.
- Пользовательские изображения доски, объявлений, печатей, значков и креплений.
- Русский и английский интерфейс.

## Совместимость

- **Foundry Virtual Tabletop:** v14
- **Текущая версия:** 1.3.6
