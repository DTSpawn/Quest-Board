# Quest Board v0.9.0 — Foundry VTT v14

Интерактивные доски объявлений с независимыми списками заданий, пергаментными объявлениями и настраиваемым оформлением.

## Установка
1. Распакуйте папку `quest-board` в `Data/modules/`.
2. Перезапустите Foundry VTT.
3. Включите Quest Board в настройках модулей мира.
4. Для выбора оформления откройте **Настройки игры → Quest Board → Настройки оформления**. Пункт доступен ведущему (GM).

## Темы оформления
В настройках мира доступны:
- **Средневековое фэнтези** — стандартная тема.
- **Стимпанк** — тот же комплект графических ресурсов-заглушек с медно-сепийной цветовой обработкой.
- **Киберпанк** — тот же комплект графических ресурсов-заглушек с холодной цветовой обработкой.
- **Свой стиль** — пользовательские изображения, выбираемые через файловый менеджер Foundry.

Для собственного стиля можно указать:
- фон доски;
- фон маленького объявления;
- фон большого объявления;
- изображение сургучной печати;
- изображение кнопки/гвоздя.

Все поля необязательны. Пустое поле использует стандартный ресурс модуля. Пользовательские файлы остаются в хранилище Foundry; модуль сохраняет только их пути. При выборе другой готовой темы пользовательские пути не удаляются.

## Возможности
- Несколько независимых досок в одном мире.
- Создание, редактирование и удаление объявлений.
- Публикация объявлений для игроков.
- Свободное размещение листов на доске.
- Просмотр объявления с подписью автора.
- Опциональная сургучная печать.
- Ссылки и привязка Journal Entry по UUID.
- Размещение специального Tile на сцене.
- Кнопка менеджера в инструментах сцены.
- Общие настройки оформления мира, доступные GM.

## Примечания
В версиях Steampunk и Cyberpunk пока используются те же изображения-заглушки, что и в Medieval Fantasy; различие темы пока задаётся CSS-обработкой. Отдельные тематические графические наборы можно добавить позднее без изменения структуры данных объявлений.


## Тематические печати
Для каждого из 11 встроенных стилей используется собственная печать. Печать автоматически выбирается по стилю доски и объявления; пользовательское изображение печати по-прежнему имеет приоритет, если включено переопределение изображений.
