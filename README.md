# Quest Board v1.5.9 — Foundry VTT v14

Интерактивные доски объявлений для Foundry Virtual Tabletop. Модуль поддерживает независимые доски, квестовые записи и отдельные городские объявления, которые можно публиковать на досках.

## Установка

1. Скопируйте папку `quest-board` в `Data/modules/`.
2. Перезапустите Foundry VTT.
3. Включите **Quest Board** в настройках модулей мира.
4. Откройте менеджер досок через инструмент модуля или соответствующую кнопку интерфейса.

## Возможности

- Несколько независимых досок в одном игровом мире.
- Создание, редактирование, публикация и удаление квестовых объявлений.
- Отдельный тип городских объявлений, не требующий квестовой категории, награды или срока выполнения.
- Библиотека из 330 готовых объявлений для 11 тематических стилей.
- Случайная публикация объявления из библиотеки с учётом выбранного стиля оформления.
- Свободное размещение листовок на доске.
- Случайный размер новых листовок в диапазоне 85–105%.
- Вероятность случайного наклона листовки — 75%; допустимые углы: ±5°, ±10°, ±15° и ±20°.
- Ручной поворот с шагом 5° в диапазоне от −20° до +20°.
- Для случайно создаваемых объявлений печать/сургучный оттиск не добавляется.
- Полный текст объявления передаётся в макет; размер шрифта заголовка и описания подстраивается под доступную область пергамента.
- Просмотр объявления с подписью автора.
- Сохранение игроком независимой копии объявления в разделе «Сохранённые объявления»; удаление сохранённой копии не затрагивает оригинал.
- Ссылки и привязка Journal Entry по UUID.
- Размещение специального Tile на сцене и открытие менеджера через инструменты сцены.
- Настройки оформления мира, доступные ведущему (GM).

## Темы оформления

Встроенные стили: Medieval Fantasy, Steampunk, Cyberpunk, High Fantasy, Dark Fantasy, Gothic Horror, Sci-Fi, Modern, Wild West, Solarpunk и Post-Apocalyptic. Также доступен **Custom Style** с пользовательскими изображениями.

Для собственного стиля можно задать фон доски, фон маленького и большого объявления, изображение печати и крепления. Все поля необязательны: пустое поле использует ресурс выбранного стиля. Модуль сохраняет пути к пользовательским файлам, а не копирует сами файлы.

## Библиотека объявлений

Готовые объявления находятся отдельно от логики модуля в `data/notices.json`. Записи содержат текстовые поля и привязку к стилю. Файл можно редактировать вручную; сохраняйте корректный JSON и структуру существующих записей.

При случайной публикации модуль выбирает объявление из записей, подходящих под текущий стиль. Повторный выбор не исключён: защита от повторов между последовательными публикациями не реализована.

## Совместимость

- Foundry Virtual Tabletop: v14.
- Минимальная и проверенная версия указаны в `module.json`.

## Разработка

В репозитории основная структура следующая:

- `module.json` — метаданные и версия модуля.
- `scripts/quest-board.js` — логика модуля.
- `styles/quest-board.css` — оформление интерфейса и объявлений.
- `templates/` — Handlebars-шаблоны.
- `lang/` — локализации.
- `data/notices.json` — библиотека готовых объявлений.
- `assets/` — графические ресурсы.

История изменений — в [CHANGELOG.md](CHANGELOG.md).


## Notice libraries

Ready-made public notices are stored separately by language:
- `data/notices.ru.json` — Russian notice library.
- `data/notices.en.json` — English notice library.

The module selects the library using the Foundry VTT interface language. The English library currently contains twenty original notices for each of the eleven supported styles.
