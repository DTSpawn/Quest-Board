# Quest Board v1.6.1 — Foundry VTT v14

Интерактивные доски объявлений для Foundry Virtual Tabletop. Ведущий создаёт независимые доски, публикует квесты и городские объявления, а игроки могут сохранять интересные объявления в личный список.

## Установка

1. Скачайте установочный ZIP из [раздела Releases](https://github.com/DTSpawn/Quest-Board/releases).
2. Распакуйте архив и убедитесь, что внутри находится папка `quest-board`.
3. Переместите её в `Data/modules/` вашей установки Foundry VTT.
4. Перезапустите Foundry VTT и включите **Quest Board** в настройках модулей мира.

Файл `module.json` должен находиться непосредственно в `Data/modules/quest-board/`, без дополнительной вложенной папки.

## Возможности

### Доски и объявления
- Несколько независимых досок в одном игровом мире.
- Создание, редактирование, публикация и удаление квестовых объявлений.
- Отдельный тип городских объявлений — без обязательной квестовой категории, награды или срока выполнения.
- Пять категорий квестов, а также возможность оставить запись без категории.
- Ссылки на внешние ресурсы и записи/страницы Foundry Journal.
- Размещение интерактивного значка доски на сцене.

### Личный список игрока
- Игрок может сохранить объявление с помощью действия **«Взять объявление»**.
- Объявление сохраняется как независимая копия в разделе **«Сохранённые объявления»**.
- Сохранённые записи доступны игроку отдельно от досок и оригинальных публикаций.
- Удаление записи из личного списка не удаляет и не изменяет оригинальное объявление на доске.

### Случайные объявления для ведущего
- Действие **«Случайное объявление»** выбирает случайную запись из библиотеки готовых объявлений.
- Выбор ограничивается текущим стилем оформления доски.
- Объявление сразу создаётся и публикуется на доске — без промежуточного редактора и выбора категории.
- Повторное выпадение одного и того же объявления возможно.

### Библиотека объявлений
- Русская библиотека: 330 объявлений.
- Английская библиотека: 220 оригинальных объявлений — по 20 для каждого из 11 стилей.
- Язык библиотеки автоматически выбирается по языку интерфейса Foundry VTT.
- Тексты хранятся отдельно от JavaScript в JSON-файлах: `data/notices.ru.json` и `data/notices.en.json`.

### Оформление листовок
- 11 встроенных тем: Medieval Fantasy, Dark Fantasy, High Fantasy, Sci-Fi, Cyberpunk, Solarpunk, Steampunk, Modern, Post-Apocalyptic, Gothic Horror и Wild West.
- Также доступен Custom Style с пользовательскими изображениями.
- Случайный размер новых листовок — 85–105%.
- Вероятность случайного наклона — 75%; шаг угла — 5°, диапазон от −20° до +20°.
- Полный текст объявления подгоняется под область пергамента; размер шрифта заголовка и описания автоматически уменьшается при необходимости.
- Случайные объявления создаются без сургучной печати/оттиска.

### Дополнительные инструменты
- Шаблоны для повторного использования заготовок.
- Архив завершённых, просроченных, отозванных и проваленных объявлений.
- Настройки внешнего вида досок и листовок для ведущего.
- Русская и английская локализации интерфейса.

## Структура проекта

- `module.json` — метаданные и версия модуля.
- `scripts/quest-board.js` — логика модуля.
- `styles/quest-board.css` — оформление интерфейса и объявлений.
- `templates/` — Handlebars-шаблоны.
- `lang/` — локализации.
- `data/notices.ru.json` — русская библиотека объявлений.
- `data/notices.en.json` — английская библиотека объявлений.
- `assets/` — графические ресурсы.
