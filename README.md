# Quest Board

Интерактивные доски объявлений и заданий для Foundry Virtual Tabletop. Ведущий публикует квесты и городские объявления, а игроки могут сохранять интересные публикации в личный список.

## Установка

1. Скачайте ZIP-архив модуля из [раздела Releases](https://github.com/DTSpawn/Quest-Board/releases).
2. Распакуйте архив. Внутри должна находиться папка `quest-board`.
3. Переместите папку в `Data/modules/` вашей установки Foundry VTT.
4. Перезапустите Foundry VTT и включите **Quest Board** в настройках модулей мира.

Файл `module.json` должен находиться непосредственно в `Data/modules/quest-board/`.

## Совместимость

Foundry Virtual Tabletop v14. Поддерживаются русский и английский языки интерфейса.
